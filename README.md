# Автотесты Automation in Testing

Maven-проект с UI-автотестами сайта [Automation in Testing](https://automationintesting.online/). Используются Java, Selenide, JUnit 5 и паттерн Page Object.

## Требования

- JDK 11 или новее
- Apache Maven 3.8+
- Google Chrome

## Реализованные сценарии

1. **Авторизация администратора** — открытие административной страницы, вход с тестовыми учётными данными и проверка появления раздела Rooms.
2. **Создание комнаты** — авторизация, заполнение названия, типа комнаты, доступности, цены и описания; проверка появления созданной комнаты в списке.

Для каждого теста административная страница открывается заново. Название комнаты генерируется уникальным, чтобы повторные запуски не конфликтовали с ранее созданными данными.

## Структура

```
src
├── main/java/ru/yourcompany/autotest/pages
│   ├── AdminPage.java
│   └── RoomCreatePage.java
└── test/java/ru/yourcompany/autotest
    └── AdminTests.java
```

## Запуск

Выполните из корневой папки проекта:

```bash
mvn clean test
```

Selenide управляет запуском браузера и ожиданием элементов.

## Тестовые данные

- Логин: `admin`
- Пароль: `password`

## Видео выполнения

Для сдачи задания запустите `mvn clean test` локально и запишите экран во время выполнения обоих тестов (например, OBS Studio или встроенной записью экрана). Видео нужно приложить отдельно к сдаче либо разместить по доступной ссылке.

> Скринкаст не генерируется Maven автоматически — его необходимо записать локально.
